# SwiftDeploy

A declarative CLI tool that generates Nginx, Docker Compose, and OPA policy configs from a single manifest.yaml and manages the full container lifecycle with policy enforcement.

## Prerequisites

- Docker installed
- Python 3.10+
- pip packages: jinja2, pyyaml

Install:

    pip3 install jinja2 pyyaml

## Quick Start

    git clone https://github.com/Ada-Mazi/swiftdeploy
    cd swiftdeploy
    pip3 install jinja2 pyyaml
    docker build -t nneoma-swiftdeploy:latest app/
    ./swiftdeploy deploy

## Project Structure

    swiftdeploy/
    manifest.yaml        - single source of truth
    swiftdeploy          - CLI tool
    app/                 - API service (Python)
      main.py
      Dockerfile
    templates/           - Jinja2 templates
      nginx.conf.j2
      docker-compose.yml.j2
    policies/            - OPA Rego policies
      infrastructure.rego
      canary.rego
      data.json
    nginx.conf           - generated by init
    docker-compose.yml   - generated by init
    history.jsonl        - metrics history
    audit_report.md      - audit report

## Subcommands

### init
Generates nginx.conf and docker-compose.yml from templates

    ./swiftdeploy init

### validate
Runs 5 pre-flight checks

    ./swiftdeploy validate

### deploy
Runs OPA pre-deploy policy check, builds image, starts stack

    ./swiftdeploy deploy

### promote
Runs OPA pre-promote canary safety check, switches mode

    ./swiftdeploy promote canary
    ./swiftdeploy promote stable

### status
Live dashboard showing metrics and policy compliance

    ./swiftdeploy status

### audit
Generates audit_report.md from history.jsonl

    ./swiftdeploy audit

### teardown
Removes all containers, networks, volumes

    ./swiftdeploy teardown
    ./swiftdeploy teardown --clean

## API Endpoints

- GET /        welcome message with mode, version, timestamp
- GET /healthz liveness check with status and uptime
- GET /metrics Prometheus metrics
- POST /chaos  simulate degraded behaviour (canary only)

## OPA Policies

Infrastructure policy blocks deploy if:
- Disk free less than 8GB
- CPU load greater than 2.0
- Memory free less than 10%

Canary safety policy blocks promotion if:
- Error rate greater than 1%
- P99 latency greater than 500ms
